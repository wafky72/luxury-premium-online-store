## 🛒 Cómo comprar

```
   1              2                3                4
 Buscá   →    Agregá al   →    Elegí envío   →   Seguí tu
 el         carrito          y pagá           pedido
 producto
```

1. **Buscá el producto** — Usá el buscador o navegá por categoría. Cada ficha muestra precio final, origen y tiempo estimado de entrega.
2. **Agregalo al carrito** — No hace falta crear cuenta: el carrito funciona como invitado y se conserva en tu dispositivo.
3. **Elegí envío y pagá** — Ingresás la dirección, ves el costo de envío e impuestos, aplicás cupón si tenés y confirmás.
4. **Seguí tu pedido** — Recibís un número de orden y notificaciones por email y SMS en cada cambio de estado.

## 💳 Medios de pago

Tarjetas de crédito y débito, billeteras digitales y pasarelas locales. El cobro se confirma por webhook, así que el estado del pedido se actualiza solo, sin intervención manual.

> Las pasarelas activas se configuran por entorno. Ver [Para desarrolladores](#️-para-desarrolladores) para las integraciones implementadas en este repositorio.

## 🚚 Envíos y seguimiento

- **Cálculo previo** — El costo de envío y los impuestos de importación se muestran antes de confirmar la compra.
- **Socios logísticos** — Integración con couriers para generar la guía y sincronizar el estado.
- **Seguimiento público** — Consultá tu pedido con el número de orden, sin iniciar sesión.
- **Estados del pedido** — `Pendiente → Confirmado → En preparación → Despachado → En tránsito → Entregado`.

---

## 🛡️ Garantía y devoluciones

- **Garantía de devolución del 100%** ante daño o falta de disponibilidad del producto.
- **Verificación antifraude** en el momento del pedido, mediante historial de entregas del comprador.
- **Datos protegidos** — Los identificadores personales se envían hasheados (SHA-256) a las plataformas de medición.

<summary><strong>Puesta en marcha</strong></summary>

<br/>

**Requisitos:** PHP 8.3+ y Composer · Node.js 20+ y npm · MySQL 8+ · Redis (opcional)

```bash
# Backend
cd backend
composer install
cp .env.example .env          # configurá DB_* y las claves de integración
php artisan key:generate
php artisan migrate --seed
php artisan serve             # http://localhost:8000  ·  panel en /admin
php artisan queue:work        # en otra terminal: las notificaciones van a cola

# Frontend
cd frontend
npm install
cp .env.example .env          # VITE_API_URL debe incluir el prefijo /api/v1
npm run dev                   # http://localhost:5173

# Ambos a la vez, desde la raíz
npm install && npm run dev
```

<details>
<summary><strong>⚠️ Pendientes conocidos</strong></summary>

<br/>

- **`php artisan` no corre desde `backend/`.** [artisan:14](backend/artisan#L14) requiere `./bootstrap/app.php`, pero `bootstrap/` está en `backend/app/bootstrap/`, y ese archivo define `basePath` en `backend/app/`, donde no están `config/` ni `storage/`. Hay que unificar la estructura antes de ejecutar los comandos de arriba.
- **`backend/.env.example` tiene una `DB_PASSWORD` real versionada en git.** Rotá esa credencial y dejá el campo vacío.
- **`frontend/.env.example` apunta a `/api` y no a `/api/v1`.** El cliente Axios llama rutas como `/products`, así que la URL base necesita el `/v1`.
- **El service worker nunca se registra.** `sw.js` y `manifest.json` existen y el manifest está enlazado, pero nadie llama a `navigator.serviceWorker.register()`, así que la PWA todavía no se instala ni funciona offline.
- **Ruta de depuración en producción.** `GET /api/v1/debug-session` expone el token CSRF y todas las cabeceras de la petición. Sacala antes de publicar.
- **Nagad, SSLCommerz y Pathao son rutas sin driver.** Existen los webhooks y los campos de configuración; solo `BkashGateway` y `SteadfastService` están implementados.
- **Los tests son plantillas.** `backend/app/tests/` solo contiene los `ExampleTest` del framework.

</details>

## ❓ Preguntas frecuentes

<details>
<summary><strong>¿Necesito crear una cuenta para comprar?</strong></summary>
<br/>
No. El carrito y el checkout funcionan como invitado. Crear una cuenta te permite guardar direcciones, ver el historial de pedidos y usar la lista de favoritos.
</details>

<details>
<summary><strong>¿Cuánto tarda en llegar mi pedido?</strong></summary>
<br/>
Depende del almacén de origen y del destino. El plazo estimado se muestra en la ficha del producto y se confirma antes de pagar.
</details>

<details>
<summary><strong>¿Los precios incluyen impuestos de importación?</strong></summary>
<br/>
Sí. El total del checkout incluye envío e impuestos calculados por adelantado, para que no haya cargos sorpresa en la aduana.
</details>

<details>
<summary><strong>¿Cómo sigo mi pedido?</strong></summary>
<br/>
Con el número de orden podés consultar el estado en cualquier momento, sin iniciar sesión. Además recibís avisos por email y SMS en cada cambio.
</details>

<details>
<summary><strong>¿Puedo devolver un producto?</strong></summary>
<br/>
Sí. Aplica la garantía de devolución del 100% en casos de daño o falta de disponibilidad, según la política de devoluciones.
</details>

<details>
<summary><strong>¿Los productos son originales?</strong></summary>
<br/>
Sí. Todos los artículos son nuevos y se compran a proveedores y distribuidores autorizados en el mercado de origen.
</details>
